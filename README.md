# SteamSDK

Steamworks SDK headers, import libraries and runtimes shared by MetaHookSv projects.

## Contents

- `steam/`: Steamworks SDK headers using the standard `steam/` include layout.
- `lib/steam_api.lib`: Windows x86 import library.
- `lib/steam_api64.lib`: Windows x64 import library.
- `bin/steam_api.dll`: Windows x86 runtime.
- `bin/steam_api64.dll`: Windows x64 runtime.
- `bin/linux32/libsteam_api.so`: Linux x86 runtime.
- `bin/linux64/libsteam_api.so`: Linux x64 runtime.

These files are Steamworks SDK v1.65 (23 July 2026), copied without changes.
See [STEAM-SDK-NOTICE.md](STEAM-SDK-NOTICE.md) for their source paths and hashes.
