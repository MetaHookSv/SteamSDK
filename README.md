# SteamSDK

Steamworks SDK headers, import library and runtime shared by MetaHookSv projects.

## Contents

- `steam/`: Steamworks SDK headers using the standard `steam/` include layout.
- `lib/steam_api.lib`: Windows x86 import library.
- `bin/steam_api.dll`: Windows x86 runtime.

These files were imported without changes from
[SteamAppsLocation](https://github.com/MetaHookSv/SteamAppsLocation) at commit
`dc8dbec`, where they were stored in `thirdparty/SteamSDK`.
